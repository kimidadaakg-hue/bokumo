# BOKUMO Instagram フォロー運用ガイド

## 目的
1日20件、子育てママを中心にフォローして相互フォローを獲得する。
Instagram Graph API はフォロー操作を提供していない（=自動化不可）ので、**手動フォロー + 履歴管理スクリプト** で運用する。

## 毎日のフロー

### 朝（5〜10分）

1. **iPhone or PC で Instagram を開く**
2. 上の「種アカウント」のうち1〜2件を選んでプロフィール画面へ
3. 「フォロワー」タブを開く
4. リストをスクロールしながら、以下の条件に当てはまる人を **20件** フォロー：

   ✅ プロフィール画像が **本人っぽい / 子供っぽい**（風景・ロゴ等の業者は除外）
   ✅ 直近1ヶ月以内に投稿してる（アクティブ）
   ✅ 札幌 / 北海道 / 道産子 などプロフィールに記載
   ✅ フォロワー数 100〜5000 程度（極端に多い／少ないは避ける）
   ✅ 子供の写真や子育て関連の投稿がある
   
   ❌ ビジネスアカウント（店・サービス系）→ 別カテゴリ
   ❌ プロフィール非公開
   ❌ フォロー数 >> フォロワー数（フォローバック狙いの古参 spam）

5. **フォローしたら、すぐ履歴記録**：
   ```bash
   cd /Volumes/外付けSSD/クロード/bokumo
   python3 scripts/instagram/follow_manager.py add @username --source @kushio181011 --note "札幌、3歳児ママ"
   ```
   または、私（Claude）に「`@user1 @user2 @user3 を @kushio181011 のフォロワーから20件フォローした、記録して`」と一括で頼んでもOK。

### 状況確認

```bash
python3 scripts/instagram/follow_manager.py status
```
→ 今日のフォロー数 / 累計 / 相互フォロー率を表示

### 相互フォロー成立時

数日後に「フォローしてくれた」と通知が来たら：
```bash
python3 scripts/instagram/follow_manager.py reciprocated @username
```

## 週次（7日経過後）

### アンフォロー候補確認
```bash
python3 scripts/instagram/follow_manager.py candidates
```
→ 7日経ってフォロー返してこない人リスト

### アンフォロー実行
1. リスト見ながら IG アプリで手動アンフォロー
2. アンフォロー記録：
   ```bash
   python3 scripts/instagram/follow_manager.py unfollow @username
   ```

## 期待効果

| 経過 | 累計フォロー | 相互成立（30%想定） | BOKUMO フォロワー数増 |
|---|---|---|---|
| 1週間 | 140 | 42 | +30〜50 |
| 1ヶ月 | 600 | 180 | +150〜250 |
| 3ヶ月 | 1,800 | 540 | +500〜800 |

実際は投稿の魅力度・タイミング・運次第。フォロー返し率20〜40%が一般的。

## 注意

- **1日40件以上は spam 判定リスク**（Instagram の公式上限なし、20〜30件が無難）
- **フォローしすぎて「フォロー数 > フォロワー数」が大きくなりすぎないよう注意** → アルゴリズム評価が下がる
- **アンフォローも1日10〜15件まで**（短時間に大量実行はNG）
- フォローしたら **その日のうちに記録**（後日まとめてだと忘れる）
